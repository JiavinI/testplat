# TestPlat 领域术语

本文件只定义产品术语，不定义 YAML 字段、数据库结构或技术实现。

| 术语 | 定义 | 不等同于 |
| --- | --- | --- |
| 平台实例（Platform Instance） | 一套由单一组织内部使用的 TestPlat 部署。P0 可以服务多个团队和测试项目，但不提供租户级隔离。 | 测试项目、多租户平台。 |
| 测试项目（Test Project） | 平台中管理资产、目标系统、环境、运行、命名和后续配额的业务容器。P0 中它不是独立租户，也不是完整的平台用户授权边界。 | 被测系统、租户、完整权限范围。 |
| 归档项目（Archived Project） | 禁止新同步、发布和运行但仍按保留策略保存历史事实、且可由管理员恢复的测试项目状态。 | 永久删除、暂停单个定时任务、删除历史运行。 |
| 目标系统（Target System） | 测试项目下可被 Scenario 通过 API 或 Browser 调用的逻辑业务应用或服务，以 `targetRef` 引用。 | 测试项目、环境、SQL/ES 受控连接。 |
| 环境（Environment） | 用户一次选择的项目级运行上下文，例如 `test`；它分别解析目标系统的 API/Web 部署绑定和受控连接的 SQL/ES 连接绑定。 | 测试数据、凭据、单个目标系统部署。 |
| 平台用户 | 以不可变 `userId` 标识、登录 TestPlat Web 并受平台角色控制的人；登录名不可回收复用，显示名称可以改变。 | 被测系统账号、Worker 服务身份、某次登录会话。 |
| 自助注册账号（Self-Registered User） | 通过公共注册创建并立即处于 `active`、自动拥有普通用户角色的平台用户；P0 可运行所有项目的已发布资产，但只能查看自己的 `masked` 结果，管理员或超管后续可以升权、换角色或禁用。 | 待审批账号、管理员账号、超管账号、项目成员关系。 |
| Web 会话（Web Session） | 平台服务端保存、由浏览器通过 `HttpOnly` Cookie 持有随机不透明标识的登录状态；支持即时撤销并受 CSRF 与来源校验保护。 | 浏览器本地 JWT、平台 API Token、被测系统认证会话。 |
| 被测系统身份（Test Identity） | 自动化运行时在目标系统中扮演的业务账号或角色。 | 平台用户、登录协议。 |
| 凭据（Credential） | 被测系统身份所需的密码、Token、Cookie 或其他机密材料，由平台加密保管。 | YAML 测试数据、平台用户密码。 |
| 受控连接（Managed Connection） | 测试项目下与目标系统并列的受控技术连接。P0 包含供 `sql.query` 使用的数据库连接，以及仅供认证 Adapter 获取一次性验证码的 Redis 连接；后续可扩展 ES。 | 目标系统、YAML 中的连接字符串、测试数据、普通 Scenario 可任意使用的 Redis。 |
| 平台系统依赖（Platform System Dependency） | Control、Worker 等平台组件使用专用服务身份访问的平台数据库、会话/队列 Redis、对象存储或调度服务；不向测试资产暴露。 | Target System、Managed Connection、可由 Scenario 查询的平台数据库。 |
| 出站网络策略（Egress Network Policy） | 部署级配置的资源类型、域名、CIDR 与端口访问边界；区分平台组件依赖和测试执行出站，项目只能在允许范围内收紧，显式例外由超管审计管理。 | Target System 内容、数据库只读策略、防火墙的全部职责、浏览器直接连接数据库。 |
| 执行 Adapter（Execution Adapter） | 随平台部署安装、以稳定 ID 和版本声明特定协议或外部系统执行能力的受控组件。 | YAML 资产、Web 上传脚本、用户自定义运行时代码、目标系统。 |
| Worker 服务身份（Worker Service Identity） | Worker 使用一次性注册 Token 加入平台后获得的唯一、可轮换、可撤销机器身份，只能访问执行所需最小接口与当前任务材料。 | 平台用户、共享镜像密钥、被测系统身份、认证 Profile。 |
| 认证 Profile | 指定某个身份在某个目标系统、通道和环境中如何建立并验证会话的规则。 | 凭据本身、业务场景。 |
| 执行身份引用（Actor Reference） | `auth.actorRef` 声明的项目内稳定逻辑身份槽位，例如 `buyer.primary`。平台按环境、目标系统和通道将其唯一解析为被测系统身份、认证 Profile 与凭据版本引用。 | 平台角色、业务角色分类、真实用户名、账号池选择器、密码、Token、会话。 |
| 身份租约（Identity Lease） | P0 中对 `environment + targetRef + actorRef` 的排他运行占用；一个 Run 所需的全部租约在运行前原子获取，同一 Run 内跨 API/Browser 通道共享，共享同一键的其他 Run 按键 FIFO 等待。 | BrowserContext、凭据锁、业务数据隔离、同一账号并发配置、执行中逐步加锁、全局队列阻塞。 |
| 测试资产（Asset） | 版本化 YAML 中的 API/Page 契约、DataSet、Flow、Scenario、Suite 或 ApiCheckSet。 | 平台配置实体。 |
| 数据作用域（Data Scope） | 测试数据的使用范围：可复用的 DataSet、Scenario 局部变量、Step 内联输入或前置步骤显式输出。 | 环境配置、凭据、连接配置。 |
| 值节点（Value Node） | YAML 中显式产生运行值的结构：确定地址使用 `$ref`，复杂查询使用 `$select`，字符串渲染使用 `$template`，特殊业务对象可用 `$literal` 转义。 | 隐式变量替换、任意表达式或脚本执行。 |
| 受限引用路径（Restricted Reference Path） | `$ref` 使用的确定性路径：保留根后接点号字段、特殊字段方括号或固定非负数组下标；不包含过滤、通配符、切片、函数和计算。 | JSONPath 查询、任意表达式、动态脚本。 |
| 查询参数（Select Parameter） | 当前 `$select` 内由 `params` 声明、在静态查询路径中以 `$params.<name>` 使用的局部类型化绑定。 | `$ref` 全局根、字符串插值、环境变量。 |
| 查询子集（Select Query Subset） | TestPlat 按 DSL 版本定义的受限 JSONPath 能力，用于字段访问、通配和类型化条件过滤。 | 某个 JSONPath 库的全部语法、脚本或任意表达式。 |
| API 请求契约（API Request Contract） | ApiContract 中将显式业务输入规范化映射为路径参数、查询参数、业务请求头和请求体的定义，并绑定一个逻辑目标系统。 | 真实环境 URL、认证信息、测试账号、Step 任意拼装的 HTTP 请求。 |
| API 成功语义（API Success Semantics） | ApiContract 中由 HTTP 状态接受规则和有稳定 ID 的业务断言共同定义的正常成功条件。 | 只收到 HTTP 响应、只检查 HTTP 200、Scenario 任意忽略契约结果。 |
| 页面契约（Page Contract） | `PageContract` 中对一个逻辑目标系统内的页面、可选结构化入口和稳定元素进行版本化描述的资产。 | 具体浏览器会话、环境绝对 URL、任意页面脚本。 |
| 页面入口（Page Route） | PageContract 中可选的 `route`，使用相对路径、显式输入、路径参数和查询参数描述可直接导航的入口；无入口的动态页面仍可拥有元素契约。 | 认证信息、绝对 URL、请求头、当前浏览器所在页面。 |
| 页面引用（Page Reference） | 每个 Browser Step 显式声明的 `pageRef`，用于选择页面和元素契约；引用本身不会触发导航或断言当前 URL。 | 最近打开页面的隐式状态、Browser 会话、页面跳转动作。 |
| 运行时能力值（Runtime Capability Value） | 由执行动作产生、仅在当前 Run 的受限运行时作用域内有效的不透明能力引用；可经允许的 Step/Flow 边界传递，但不是普通可序列化资产值。P0 的 `pageHandle` 属于此类。 | string、json、DataSet 值、Scenario 外部输入、可恢复持久化数据。 |
| 运行时页面句柄（Runtime Page Handle） | `browser.open` 或产生新页面的动作返回的 `pageHandle` 类型页面实例能力，通过 `pageHandleRef` 在同一 Run、同一 BrowserContext 内显式传递。 | string、PageContract、标签页序号、当前页隐式状态、跨 Run 页面引用。 |
| 结构化元素定位器（Structured Element Locator） | `PageContract.elements` 中由可选 iframe 链、可选容器链和最终定位器组成的严格唯一定位定义；P0 只支持 `role`、`label`、`text`、`testId` 和标准 `css`，后续定位策略通过 DSL 版本扩展。 | 自动取第一个元素、候选回退、P0 XPath、JavaScript 或 Playwright 私有选择器。 |
| Browser 动作结果（Browser Action Result） | Browser Step 的稳定结构化结果：公共 `result.page` 描述动作后的页面句柄、URL 和标题，读取和截图动作分别增加 `result.element` 与 `result.artifact`。 | 控制台文本、完整 DOM 快照、Worker 本地文件路径。 |
| 受控查询动作（Managed Query Action） | P0 中由 Scenario 或 Flow 通过逻辑连接执行的 `sql.query` 只读动作，使用参数化输入和有界结果；后续可增加结构化 `es.search`。 | 任意数据库脚本、自由 HTTP 请求、连接凭据、写入工具。 |
| 查询动作结果（Query Action Result） | P0 SQL 查询以 `result.rows` 和含数量、截断、耗时的 `result.meta` 表达；后续 ES 保留自身 `hits` 语义，不强行归一。 | 匿名 `items`、数据库或 ES 驱动的原始响应。 |
| SQL 执行能力（SQL Execution Capability） | 由数据库 Adapter、受控连接、参数绑定、策略、结果和审计组成的通用执行能力；可被只读流程、后续人工 SQL 工具和后续受控写库流程复用。 | `SqlContract`、某条具体 SQL、无限制通用 SQL 入口。 |
| SQL 契约（SqlContract） | 描述一项命名、版本化 SQL 操作的测试资产，声明其输入、静态语句、参数映射、操作效果、结果和风险约束；未来自动化流程写库必须通过该资产发布。 | SQL 执行器、数据库连接、人工 SQL 工具、任意 SQL 模板。 |
| SQL 技术结果（SQL Technical Result） | SQL 执行能力返回的稳定通用结果；查询由行与元数据组成，写操作由影响行数与元数据组成。 | `SqlContract` 对调用者公开的业务字段、数据库驱动原始响应。 |
| 契约业务输出（Contract Business Output） | Contract 从技术动作结果中投影并公开的稳定命名字段，使调用者不依赖底层协议、表、列或驱动细节。 | 完整原始响应、步骤内部临时变量、隐式共享状态。 |
| 资产值类型（Asset Value Type） | 可调用资产共享的版本化类型语言，首期包含字符串、整数、精确小数、布尔、日期、时间、封闭对象、列表和任意 JSON 值。 | 编程语言对象类型、数据库专有类型、隐式类型转换。 |
| 必填性（Requiredness） | 一个输入或对象字段是否必须存在；可选字段缺失表示该字段不存在。 | 可空性、默认值、值为 `null`。 |
| 可空性（Nullability） | 一个已经存在的输入、字段或输出是否允许显式值 `null`。 | 字段缺失、可选输入、空字符串、空集合。 |
| 转换操作符（Transform Operator） | 对运行时数据执行确定性加工的通用、版本化操作，例如对象组合、金额计算或集合筛选。 | 任意脚本、公司业务函数、对原始步骤输出的原地修改。 |
| 断言操作符（Assertion Operator） | 对实际值执行确定性校验的版本化运算。比较类使用 `eq`、`ne`、`gt`、`gte`、`lt`、`lte` 等通行缩写，语义类使用 `exists`、`contains` 等清晰单词。 | 用符号、通用取反或运行时猜测隐藏实际断言语义。 |
| 步骤动作（Step Action） | Step 中由 `action` 标识的一项确定操作；公共步骤语义与该动作需要的专属参数共同构成可校验的执行单元。 | 任意脚本、隐式动作推断、完整 Scenario。 |
| 步骤输出（Step Output） | Step 成功完成后一次性公开的、具名且不可变的类型化值，供当前作用域内后续步骤显式引用。 | 当前动作原始结果、可变全局变量、Flow 内部状态。 |
| 显式匿名认证（Explicit Anonymous Authentication） | API 或 Browser Step 明确声明无需被测系统身份执行，而不是因遗漏身份配置而被动匿名。 | 缺失认证配置、认证失败、受控连接凭据。 |
| 生命周期状态（Lifecycle Status） | Run 或 Step 当前所处的有限状态，例如排队、运行、通过、失败、跳过或取消。 | 认证失败、超时、断言失败等具体原因。 |
| 失败分类（Failure Classification） | 用稳定类别、错误码和可读信息描述一次拒绝或失败的原因，并与生命周期状态分开保存。 | 为每种错误创造新的 Run 或 Step 状态。 |
| 清理阶段（Cleanup Phase） | Scenario 主步骤结束后执行的显式收尾阶段，用于清理测试数据、释放运行资源或关闭会话，并独立记录执行结果。 | 自动回滚、对不可逆业务动作的重放。 |
| 执行通过率（Execution Pass Rate） | 已结束且确实进入执行的 Scenario Run 中，通过数占通过与失败总数的比例；拒绝、取消、排队和运行中状态分别统计。 | 请求受理率、拒绝率、Suite 成员通过率、把未执行 Run 算作失败。 |
| 重放声明（Replay Declaration） | 资产作者对某种再次执行用途作出的显式授权；P0 支持 Step 的 `wait` 申请，以及只读 ApiContract 上限与 Step 申请共同允许的 `authRefresh`。声明随发布修订和运行快照固化。 | 自动证明动作安全、允许任意重试、网络故障重试或主动重复。 |
| 有限集合执行（Bounded Collection Execution） | 对运行时已存在的有限列表按原顺序逐项调用一个 Flow，并按原顺序聚合其输出。 | 任意循环、并发执行、动态生成步骤。 |
| 资产标识（Asset Identity） | 资产自身声明的稳定 `kind + metadata.id`，用于引用、发布、快照和历史结果关联；同一测试项目内 ID 跨类型全局唯一。 | 文件路径、显示名称、Git 提交。 |
| 资产 Schema 版本（Asset Schema Version） | YAML 根级 `apiVersion`，用于冻结资产结构和语义兼容性。 | Git 修订、资产 ID、产品发布版本。 |
| 已发布修订（Published Revision） | 用户从已完全校验的 Git 提交中发布的整个资产根原子版本，包含不可变内容、提交标识、内容摘要和验证结果。 | Git 默认分支的最新状态、单个资产、临时依赖闭包。 |
| 活动发布修订（Active Published Revision） | 测试项目当前供新手动 Run 和新定时触发使用的已发布修订引用；可以原子切换到兼容的历史已发布修订，但不改变任何修订内容。 | 覆盖历史修订、任意 Git SHA、已经形成快照的 Run 所用修订。 |
| 已同步提交（Synchronized Commit） | 平台在一次 Git 同步中固定、完整获取并对整个资产根执行校验的 commit；只有校验通过且仍被平台保存的已同步提交可以发布。 | 用户临时输入的 SHA、远端分支当前 HEAD、已发布修订。 |
| 运行快照（Run Snapshot） | 触发运行时冻结的发布修订、资产内容、环境/目标绑定、任务策略和通知配置。 | Worker 开始执行时临时读取的配置。 |
| 场景（Scenario） | 新平台唯一的业务流程执行单元，承接旧 `Case` 的职责，P0 可顺序编排 API、Browser、SQL 只读查询和受控扩展能力，并可跨多个目标系统。 | 单一 API 契约、Flow、Suite。 |
| API 校验集合（ApiCheckSet） | 针对一个 ApiContract 的命名正向或负向校验变体集合；每个变体都是可独立追踪的结果，负向变体只把明确预期的业务失败判为通过。 | 业务场景、动态生成的临时 Case、忽略认证或平台异常的开关。 |
| 执行集合（Suite） | 可运行的、显式且有序的 Scenario 列表。 | 标签或路径的动态查询结果。 |
| 首期（P0） | 产品首个正式交付闭环；被列入 P0 的能力均是发布验收硬门槛。 | 原型、可选能力、P1 或 P2。 |
| 后续阶段（P1/P2） | P0 完成后的演进阶段；提前实现时需要独立验收，但不替代 P0 完成条件。 | P0 的可选子集、未声明的隐式承诺。 |
| 可执行调用（Executable Invocation） | 手动运行、定时任务、Suite、后续平台 API 或 MCP 触发一次可运行资产时形成的统一调用请求。 | Worker 执行计划、各入口私有的参数格式。 |
| 调用幂等标识（Invocation ID） | 调用者为一次运行意图生成的稳定标识；在幂等窗口内与调用者及规范化内容共同保证重复提交只形成一个 Run。 | Run ID、Step attemptId、定时任务 scheduleRef。 |
| Scenario 输入定义（ScenarioInputDefinition） | 后续版本由 Scenario 资产声明的外部输入名称、类型、必填性、可空性和说明；P0 不开放该能力。 | Flow 或 ApiContract 输入、P0 的隐式参数。 |
| 调用输入绑定（InvocationInputBinding） | 某个运行入口为一次 Scenario 调用提供的原始输入值及来源；P0 必须为空，非空绑定应在快照形成前拒绝。 | 已验证输入、Worker 运行时变量。 |
| 已解析 Scenario 输入（ResolvedScenarioInputs） | InputBinder 校验并规范化后写入运行快照、供 Compiler 使用的不可变输入集合；P0 固化为空集合。 | 原始 Web/MCP 参数、Worker 自行读取的外部输入。 |
| 权限能力（Permission Capability） | 权限目录中稳定、可审计的操作或数据访问标识，通过可配置的角色权限映射授予；角色名称本身不决定代码中的权限分支。 | 被测系统身份、写死的角色判断、报告访问模式。 |
| 配置版本（Configuration Version） | 平台可修改配置实体每次成功变更后产生的不可变并发控制标识；更新必须携带读取时版本，避免多人编辑静默覆盖。 | Git 提交、已发布修订、凭据明文、界面更新时间。 |
| 报告访问策略（Report Access Policy） | 决定结构化运行数据以 `masked`、`revealable` 或 `raw` 方式在线展示的平台策略；raw 可以向获权用户显示实际业务请求中的认证值。P0 原始截图不参与该分级，且不包含下载或导出。 | 固定角色默认值、截图专属权限、跨通道认证共享、普通日志级别。 |
| 脱敏规则（Redaction Rule） | 测试项目默认配置、可由目标系统覆盖的业务数据隐藏规则；获权用户仍可通过揭示或 raw 视图查看平台保存的真实值。 | YAML 运行参数、不可审计的临时关闭开关、权限授予。 |
| 审计事件（Audit Event） | 对敏感查看、发布、配置、授权、归档和清理等平台关键操作生成的只追加记录，用于说明谁在何时对什么对象执行了什么操作及结果；不保存业务报文或凭据明文。 | Run 步骤时间线、Worker 控制台日志、业务请求响应。 |
| 通知渠道（Notification Channel） | 测试项目下由获权管理员预先配置的通知目的地与凭据边界；P0 的钉钉渠道固定机器人、群组和可选 @人设置，运行只能通过 `channelRef` 选择。 | 临时 Webhook、YAML 凭据、平台用户、单条通知事件。 |
| 平台主密钥（Platform Master Key） | 由部署系统在平台数据之外独立提供、用于保护各数据密钥的版本化根密钥；其恢复副本与业务数据备份分开保管。 | 平台用户密码、被测系统凭据、存放在数据库中的普通配置、单份数据的随机数据密钥。 |
| 维护模式（Maintenance Mode） | 平台升级窗口中阻止新运行、同步、发布和配置变更，等待已运行工作自然结束并校验队列快照兼容性的管理状态。 | 高可用切换、强制取消 Run、定时触发补跑。 |
| 传输安全模式（Transport Security Mode） | 部署级全局模式，声明平台处于受控内网 HTTP（`internal_http`）或强制 HTTPS（`https_required`）；用于约束入口暴露、外部地址、代理信任和 Cookie 安全属性。 | Target System 的业务接口协议、测试环境、用户可在运行时切换的选项。 |
