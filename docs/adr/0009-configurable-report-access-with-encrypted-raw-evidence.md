# 可配置报告访问保留加密原始业务证据

P0 加密保存平台实际捕获的业务请求响应，并通过 `masked`、`revealable`、`raw` 与可配置权限控制结构化数据展示；获权 raw 用户可以在线查看认证头、Token、Cookie、被测系统登录密码、支付密码和验证码等真实请求值。脱敏规则只分项目默认和目标系统覆盖两级，不允许 YAML 或单次运行临时修改；普通日志不输出完整原始值，所有查看和揭示均审计。截图是 P0 例外：不做图片脱敏或截图专属权限，拥有 Run 查看权限的用户可以查看原始截图。P0 不提供 raw 或截图下载导出；平台自身账号密码、Git 凭据和受控连接凭据不属于业务运行证据，不得混入报告。
