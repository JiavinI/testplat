# P0 优先保证可恢复而不承诺主动高可用

TestPlat P0 是单组织内部私有平台，先要求持久状态可备份恢复、Worker 可横向扩展和已受理运行事实不因 Worker 故障丢失，不承诺控制面主动高可用、自动故障切换或跨机房容灾。部署提供每天一次、执行时间可配置的自动备份和受控恢复命令，默认在 `Asia/Shanghai` 的 `02:00` 执行，保留最近 7 天；P0 不建设复杂备份中心、Cron、多次日备份或按项目备份。恢复基线为 `RPO <= 24 小时`、`RTO <= 4 小时`，并通过一次隔离环境恢复演练验证；这样把首期成本放在简单、可证明的恢复能力上，同时为后续依据真实可用性需求增加高可用拓扑保留空间。
