# 钉钉通知使用项目受管渠道

P0 将钉钉通知建模为测试项目下的受管通知渠道，由拥有 `manage_notification_channel` 的用户预先配置稳定 `channelRef`、机器人 Webhook、签名密钥和固定群组/@人设置；运行与定时任务只能选择已有渠道，不能临时输入 Webhook、密钥、手机号或钉钉用户标识。站内通知使用稳定平台用户 ID。渠道配置按版本冻结：普通轮换不改变已有 Run 的目标，紧急停用则覆盖全部历史版本并停止待投递及重试，不自动改发或改变 Run 结果。渠道凭据加密保存，运行快照只保存渠道引用和配置版本。这个取舍减少单次运行的临时发送灵活性，换取凭据加密、接收边界可管理、快照可解释和通知行为可审计。
