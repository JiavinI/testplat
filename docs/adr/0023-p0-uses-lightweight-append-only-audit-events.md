# P0 使用轻量只追加审计事件

P0 将敏感查看、发布、平台配置、权限变更、项目归档恢复和数据清理记录为只追加审计事件，通过可配置的 `view_audit` 能力提供 Web 查询；初始只授予超管。事件默认保留 365 天且只可配置为 90 至 730 天，保存操作者、动作、对象引用、时间、结果、非敏感变更摘要和策略版本，不保存业务报文或凭据明文。必须审计的敏感查看、配置变更和 Worker 凭据使用采用失败关闭：审计无法持久化时不返回真实值、不提交变更、不发起外部动作。P0 不提供审计导出、WORM、密码学防篡改或外部合规归档，以数据库约束、权限隔离和备份获得与内部平台风险相匹配的可追溯性。
