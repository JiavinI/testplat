# 平台系统依赖与测试执行出站分离

Control 和 Worker 使用专用服务身份访问平台数据库、会话/队列 Redis、对象存储和调度服务，这些平台系统依赖不建模为 Target System 或 Managed Connection，也不向测试资产暴露。测试动作通过独立出站通道访问环境解析后的业务 Target System、业务数据库和认证专用 Redis，并服从按资源类型、域名、CIDR 和端口配置的部署策略；项目只能收紧。平台自身基础设施与云元数据地址默认拒绝，超管可以为测试平台自身等明确场景创建有范围、有期限、可审计的例外。这个边界允许 Web 管理并由 Worker 使用业务数据库/Redis，同时防止普通资产查询平台用户、凭据、权限或队列内部数据。
