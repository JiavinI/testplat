# P0 明确不做项

状态：初始产品基线派生索引；已随基线于 2026-09-24 确认。

## 1. 产品和平台非目标

- 不改造旧平台，不兼容旧平台全部行为，不将 `testplat-new` 或 `ai-test-platform` 作为运行时依赖。
- 不在通用内核中实现公司业务逻辑、固定站点、登录页面规则、环境配置或测试数据。
- 不建设多组织、多租户或项目级用户授权；P0 是单组织内部私有部署。
- 不以入口存在代替完成；没有确定输入、证据、失败、安全和验收闭环的能力不算完成。

## 2. P0 不开放的资产和运行能力

- Web 资产自由编辑、Git 写回、自动提交/PR、Agent 自动发布。
- Scenario 外部 inputs、Web 临时参数、自由接口调试台。
- `when`、任意分支、任意循环、集合并发、用户配置 retry、网络故障自动重试、整段自动重跑。
- 任意 Python、JavaScript、Shell、浏览器脚本或运行时热加载代码。
- ES 检索、SQL 写入/删除、自由 SQL 自动化入口；P0 `sql.query` 只认证 MySQL 只读。
- XPath、Firefox、WebKit、系统 Chrome；P0 Browser 只认证批准定位器和 Playwright Chromium。
- 性能压测、复杂并发、项目优先级、人工插队和同一逻辑身份提高并发数。
- 静态 API Key、OAuth、短信人工输入等未被黄金流程证明需要的认证方式。

## 3. P0 不开放的管理和数据能力

- 项目永久删除、手工删除单个 Run/报告/日志/截图/制品、绕过保留策略删除。
- 平台配置包导入导出或跨部署选择性迁移。
- raw 请求响应、截图或原始制品下载/导出；截图不做图片脱敏，也没有截图专属权限。
- MFA、SSO、邮件找回；邮件和企业微信通知。
- 审计导出、WORM、密码学防篡改或外部合规归档。
- 从 Web 恢复整个平台、复杂备份中心、Cron、多次日备份、按项目备份或差异备份。

## 4. P0 不承诺的部署能力

- 控制面主动高可用、自动故障切换、跨机房容灾、零停机升级、蓝绿部署和滚动数据库迁移。
- Kubernetes、托管中间件、OSS/MinIO 或云 KMS 作为当前本地开发和单机联调前置条件。
- 跨公网明文 HTTP；`internal_http` 只允许受控内网，扩大信任边界前必须切换 `https_required`。

## 5. 后续扩展必须重新设计的能力

`when`、ES、自动化写库、脚本工具、并发专项测试、Agent 草稿生成、MCP、XPath、图片治理、项目永久删除和配置包迁移都只能通过新的版本化能力、权限、安全、失败和验收设计开放。预留扩展位置不等于 P0 已具备入口或兼容承诺。
