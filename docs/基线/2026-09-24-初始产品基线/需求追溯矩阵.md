## P0 产品级通过门槛

- 合法资产可同步、全根校验、发布并形成不可变修订。
- 手动/定时 Run 形成不可变 Snapshot，Engine 产生确定性 Plan，Worker 完成受控执行。
- GF-01 至 GF-04 与 AC-01 至 AC-19 均有可重复证据。
- 满足已批准容量、时限、报告、恢复和安全指标；不得用后续能力替代缺失的 P0 项。
- 契约测试、故障注入和真实 MySQL/Playwright Chromium/认证 Redis/通知 Adapter 验收共同通过。
