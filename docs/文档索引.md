# TestPlat 文档索引

本目录是 TestPlat 产品需求、领域模型、设计协定、项目治理和冻结基线的统一入口。根目录不直接存放项目文档。

## 产品需求

- [产品总目标.md](产品需求/产品总目标.md)：定义平台长期目标和不可偏离的核心闭环。
- [产品需求规格.md](产品需求/产品需求规格.md)：定义产品范围、优先级、约束、非目标和后续设计顺序。

## 领域模型

- [领域术语.md](领域模型/领域术语.md)：统一平台用户、被测系统身份、凭据、资产、运行和执行等领域概念。

## 设计

- [2026-09-21-最小领域专用语言设计.md](设计/2026-09-21-最小领域专用语言设计.md)：已批准的首期 YAML 资产和执行语义设计。

后续总体技术架构、跨组件协议和模块设计统一存放在本目录，并按日期和主题命名。

## 项目治理

- [人工智能需求到验收交付工作流.md](项目治理/人工智能需求到验收交付工作流.md)：定义从产品目标、设计确认、基线冻结到实现验收的交付流程。

## 基线

`基线/` 仅存放经过批准并冻结的阶段性产品基线。当前尚未生成初始产品基线；在技术架构和跨组件协议批准前，不得提前归档或制定实施计划。

## 维护规则

1. 产品目标和需求只在 `产品需求/` 维护，设计文档不得静默改变产品范围。
2. 领域术语只在 `领域模型/` 维护，其他文档引用这里的统一定义。
3. 已批准设计发生语义变化时，必须更新批准状态并评估是否需要形成新基线。
4. 实施计划必须晚于初始产品基线冻结，并能追溯到需求和设计条目。
5. `testplat-control` 与 `testplat-engine` 的仓库级文档由各自仓库维护，不复制到本目录。
